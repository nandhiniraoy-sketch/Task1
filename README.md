# Python for Data Science - Variables and Data Types

## Project Description

This project demonstrates the basics of Python variables and data types.
It includes examples of integers, floats, strings, booleans, lists,
tuples, sets, and dictionaries. The notebook also shows how to identify
data types using the `type()` function, perform type conversion, and use
basic arithmetic operations.

## Objective

The objective of this project is to build a strong foundation in Python
programming for data science by understanding variables, data types, and
basic operations.

## Tools Used

-   Python 3
-   Jupyter Notebook

## Topics Covered

-   Variables
-   Integer (int)
-   Float
-   String (str)
-   Boolean (bool)
-   List
-   Tuple
-   Set
-   Dictionary
-   Data Type Identification using `type()`
-   Type Conversion (`int()`, `float()`, `str()`)
-   Basic Arithmetic Operations

## Examples Included

-   Real-world examples using age, salary, and student marks
-   Student performance data using a dictionary
-   Type conversion examples
-   Basic mathematical operations

## Conclusion

This project provides a basic understanding of Python variables and data
types, which are essential concepts for learning Python programming and
data science.
